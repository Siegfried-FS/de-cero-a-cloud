# Ruta de insignias oficiales gratuitas en Credly

Las insignias digitales (*badges*) avaladas por AWS a traves de plataformas como Credly permiten respaldar de manera verificable los conocimientos practicos adquiridos, sin necesidad de realizar pagos ni ingresar tarjetas de credito.

---

## 1. AWS Cloud Quest: Cloud Practitioner

**AWS Cloud Quest** es una plataforma gamificada en 3D en formato RPG donde recorres una ciudad virtual resolviendo problemas de infraestructura para clientes simulados.

- **Plataforma:** AWS Skill Builder.
- **Costo:** Gratuito (la plataforma aprovisiona consolas temporales de AWS para cada mision).
- **Insignia que otorga:** AWS Cloud Quest: Cloud Practitioner en Credly.
- **Enlace oficial:** [AWS Cloud Quest en Skill Builder](https://skillbuilder.aws/learn/FU5WCYVGKY/aws-cloud-quest-cloud-practitioner/UBG3N32DBX)

### Misiones clave que resolveras
- Creacion y configuracion de buckets en Amazon S3.
- Despliegue de instancias Amazon EC2 con servidores web basicos.
- Configuracion de Security Groups y reglas de firewall.
- Resolucion de problemas de conectividad en bases de datos relacionales.

---

## 2. AWS Cloud Quest: Generative AI

Misiones complementarias disenadas para entender la integracion practica de modelos fundacionales sin complejidad innecesaria.

- **Plataforma:** AWS Skill Builder.
- **Costo:** Gratuito en las misiones iniciales.
- **Insignia que otorga:** AWS Cloud Quest: Generative AI.
- **Enfoque:** Conceptos basicos de inferencia, embeddings y generacion asistida en la nube.

## 3. AWS SimuLearn: Cloud Practitioner

**AWS SimuLearn** combina simulaciones conversacionales con clientes de negocio simulados por inteligencia artificial y laboratorios guiados en consola.

- **Plataforma:** AWS Skill Builder.
- **Idioma:** Espanol (Latinoamerica).
- **Costo:** Gratuito.
- **Insignia que otorga:** AWS SimuLearn Cloud Practitioner en Credly.
- **Enlace oficial:** [AWS SimuLearn en Skill Builder](https://skillbuilder.aws/learning-plan/EKHCUEWUUC/aws-simulearn-cloud-practitioner-espaol-latinoamrica/14SH7JS2DU)

## 5. Como vincular tu cuenta con Credly

Para que las insignias se emitan de forma automatica a tu perfil publico:

1. Crea tu cuenta gratuita en [credly.com](https://www.credly.com/) con el mismo correo electronico que usas en AWS Skill Builder o AWS Educate.
2. En Skill Builder, accede a tu perfil y activa la casilla para compartir progreso con plataformas de certificacion.
3. Al completar el 100% de las misiones requeridas de un curso, recibiras un correo de notificacion de Credly en un plazo de 24 a 48 horas.
4. Acepta la insignia y hazla publica en tu perfil para que pueda ser enlazada a tu curriculum o compartida en LinkedIn.
