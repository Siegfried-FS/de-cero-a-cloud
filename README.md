# De cero a cloud: bitácora técnica y recursos para estudiantes

Repositorio público de recursos, grabaciones y bitácoras prácticas del programa **De cero a cloud**, una iniciativa formativa comunitaria y 100% gratuita de 12 semanas organizada por el [AWS User Group Playa Vicente](https://www.awsugplayavicente.com/) (Veracruz, México).

Este espacio está pensado para estudiantes, desarrolladores y entusiastas que buscan aprender computación en la nube con Amazon Web Services (AWS) mediante laboratorios reales, sin incurrir en costos accidentales ($0.00 USD) y dando el salto de simples consumidores de tutoriales a constructores que comparten lo aprendido con su comunidad.

## 3. Ruta de insignias oficiales, microcredenciales y Skill Builder Pro

Uno de los pilares de este curso es que cada estudiante pueda certificar sus conocimientos mediante insignias emitidas por AWS y verificables en Credly:

- **Nivel gratuito (Skill Builder y Educate):** Insignias de **AWS Cloud Quest: Cloud Practitioner**, **AWS Cloud Quest: Generative AI**, **AWS SimuLearn** y rutas de AWS Educate.
- **Suscripción Individual (Skill Builder Pro):** Desbloqueo de roles técnicos completos de Cloud Quest (Solutions Architect, Serverless Developer, Security, Machine Learning, Data Analytics, Networking).
- **Microcredenciales oficiales de AWS (*Micro-credentials*):** Evaluaciones prácticas basadas en desempeño (*performance-based*) donde resuelves retos reales dentro de consolas activas de AWS.

Para consultar el tutorial detallado de vinculación con Credly, comparativa de plataformas e insignias visuales:
[guias/insignias-oficiales-gratuitas.md](guias/insignias-oficiales-gratuitas.md).

Mecanismos verificados para obtener certificaciones gratuitas y financiar estudios:

- **AWS Builder Center Student Rewards:** Programa oficial para estudiantes verificados vía SheerID en [builder.aws.com/student-rewards](https://builder.aws.com/student-rewards) que otorga **1 año completo de suscripción gratuita a AWS Skill Builder**, créditos de $10 y $20 USD, y un **voucher de $100 USD para examen de certificación AWS** al acumular insignias.

- **AWS re/Start:** Formación intensiva gratuita de 12 semanas con vouchers al 100% para AWS Cloud Practitioner y AWS AI Practitioner.
- **AWS AI & ML Scholars:** 4,500 becas completas de Nanodegrees en Udacity y 3 meses gratis de Skill Builder.
- **Vouchers en eventos de comunidad y retos de Builder Center:** Cómo aprovechar Kahoots, Community Days y retos técnicos para recibir saldo promocional de $25 o $100 USD.
- **AWS Student Builder Groups (SBG):** Capítulos oficiales de AWS en universidades.

## 5. Kiro Pro financiado con cupones y arquitectura de seguridad IAM

Aprende a transformar los vouchers de eventos en saldo para financiar el entorno de desarrollo asistido por IA de AWS (**Kiro Desktop, Kiro CLI y Kiro Web**):

- Financia al 100% tu suscripción de Kiro Pro utilizando los cupones que otorgan en meetups y retos de fin de semana.
- Implementa una base de seguridad de nivel empresarial con **AWS Organizations** e **IAM Identity Center** bajo el principio de menor privilegio (cero permisos en infraestructura para evitar cobros sorpresa).
- Estrategia de cuidado del bolsillo para mantenerse en el plan Free permanente de $0 USD o renovar con saldo comunitario.

## 7. Política de costos transparentes y laboratorios en $0 USD

Todos los laboratorios diseñados para este programa respetan la capa gratuita (Free Tier) de AWS o se ejecutan en simuladores controlados sin riesgo financiero:

1. **Uso exclusivo de recursos en capa gratuita:** Instancias `t2.micro`, buckets S3 pequeños y pruebas efímeras.
2. **Desmantelamiento obligatorio:** Al terminar cualquier práctica, los recursos deben eliminarse de inmediato.
3. **Comprobación en consola y CLI:** No des por hecho que un recurso está borrado; valida con el comando oficial que su estado sea `terminated`.

```bash
aws ec2 describe-instances \
  --filters "Name=instance-state-name,Values=shutting-down,terminated,stopped,running" \
  --query "Reservations[*].Instances[*].[InstanceId,State.Name,InstanceType]" \
  --output table
```
